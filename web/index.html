WLED CYD Lightswitch

A touchscreen remote for WLED lights, for the ESP32-2432S028R "Cheap Yellow Display" board. Turn up to 4 WLED controllers on and off and set their colour.

Install

  1. Plug the board into this computer with a USB data cable.
  2. Click Install and choose the board's serial port.
  3. When asked, enter your WiFi details. You can also skip this and set up WiFi on the touchscreen instead.
  4. On the board, tap the 4 crosshairs to calibrate the screen, then use Settings → Lights → Find lights to add your WLED lights.
Your browser can't install firmware. Use Chrome or Edge on a computer. Firefox, Safari and phones aren't supported. Installing only works when this page is opened over https:// or from localhost.

Troubleshooting

  • No serial port listed: try a different USB cable (some only carry power). On Windows or macOS, install the CH340 driver (Windows, macOS).
  • Install gets stuck connecting: hold the board's BOOT button while clicking Install.
  • Updating: your WiFi and light settings are kept unless you choose to erase the device.
